LOGICAL.LY

On the backend, I worked on document ingestion, schema-constrained claim extraction, dynamic knowledge graph construction, and graph-based claim matching to narrow evidence candidates before final LLM evaluation.

CLUSTR REQ. 04

CLUSTR

Clustr is a local file-organization MVP that scans a folder, builds semantic representations for files, and suggests task-based clusters without automatically moving anything.

I built it with a Node.js and Express backend, a React frontend, SQLite caching, and OpenAI embeddings. The system recursively scans directories, extracts lightweight snippets from text files, caches embeddings by file path and modified time, and groups related files using cosine similarity rather than rigid folder rules.

The project stands out because it combines practical UX constraints with applied AI: users get suggested clusters and short labels, while retaining full control over whether any action should happen next.
